## 一、这是什么

智答引擎是一个**个人/团队的 AI 知识助手**：把文档、网页、飞书云文档导入知识库，创建专属 Agent，在 **QQ / 飞书机器人（群聊 + 私聊）** 或用户端即可用你的知识库回答。

主要能力：

- **知识库**：上传 PDF/DOCX/Excel/MD/TXT/CSV/JSON，自动解析、切分、向量化；支持 URL 网页导入与飞书云文档导入
- **Agent**：每个 Agent 独立绑定知识库、LLM 模型、渠道与回复风格
- **RAG 问答**：混合检索（向量 + 关键词），回答带来源引用
- **机器人渠道**：QQ 官方机器人、飞书机器人——**群内 @ 触发** 与 **私聊（单聊）**，私聊支持开放/白名单/黑名单三种权限模式
- **问答观测**：全渠道问答记录（含 Token、耗时、来源、降级状态），管理台卡片式查看
- **帮助中心**：管理台内置帮助页，支持关键词搜索、章节目录与全文阅读
- **安全**：管理员账号密码登录；用户端一次性激活码；数据全部本地存储；机器人限流防滥用

## 二、快速部署（从零开始）

### 2.1 环境要求

| 项 | 要求 |
|---|---|
| Python | 3.11+（macOS 自带为 `python3`，Windows 需自行安装并勾选 Add to PATH） |
| 系统 | macOS / Windows（本项目为 Windows 桌面应用形态，macOS 可开发运行） |
| 网络 | 首次安装依赖需联网；LLM/Embedding 走云端 API 时需联网 |

### 2.2 安装依赖（一次性）

```bash
cd backend
python3 -m venv .venv          # 创建虚拟环境
source .venv/bin/activate      # macOS/Linux；Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
```

> 国内网络建议加镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 2.3 启动服务

```bash
cd backend
./.venv/bin/python main.py     # 或先 activate 再 python main.py
```

启动成功标志（日志中）：

```
API 服务启动: http://127.0.0.1:18900
```

- 服务默认端口 **18900**，被占用时**自动换端口**（看日志里的实际端口）
- 浏览器打开管理台地址，用**管理员账号 + 密码 + 图形验证码**登录（首次启动会自动创建初始管理员，见日志或引导页）
- 健康检查：`curl http://127.0.0.1:18900/health` 应返回 `{"status":"ok",...}`

### 2.4 开发模式前端（可选）

管理台已随后端静态挂载；若改前端代码，用开发模式：

```bash
cd frontend-admin
npm install
npm run dev       # 打开 http://127.0.0.1:5173
```

### 2.5 启动常见问题

| 现象 | 原因与解决 |
|---|---|
| `zsh: command not found: python` | macOS 没有 `python`，用 `python3`，或 `./.venv/bin/python` |
| `已有实例在运行，退出` | 已有一个实例占用进程锁：先关闭旧实例再启动 |
| `Address already in use` / 端口被自动换 | 18900 被占用，应用会自动换端口，以日志为准 |
| 启动报磁盘/数据库只读 | 数据目录无权限：见[附录](#八附录数据与日志位置)确认目录可写 |

## 三、第一次使用：三步完成配置

### 第 1 步：配置 LLM 模型（必做）

管理台 → 设置 → **LLM 配置**：

1. 选择厂商模板（内置 8 家：OpenAI、DeepSeek、阿里云百炼、智谱、月之暗面、字节豆包、硅基流动等）
2. 填入 API Key，点「测试连接」
3. 建议同时配置**降级模型**（主模型不可用时自动切换）

> 支持任意 **OpenAI 兼容 API**：厂商选「自定义」，填 Base URL + Key 即可。

### 第 2 步：配置向量化（Embedding）

管理台 → 设置 → **向量化配置**：

- **云端模式**：选厂商模板（OpenAI 兼容，内置 7 家）填 Key
- **本地模式**：加载本地模型（如 `BAAI/bge-large-zh-v1.5`，无需 API Key，首次下载模型较慢）

> 未配置向量化时，知识库文档无法完成索引，问答会退化为纯 LLM 回答——请务必先配好。

### 第 3 步：创建知识库 + Agent

1. **知识库**：管理台 → 知识库 → 新建 → 上传文档（PDF/Word/Excel/MD/TXT/CSV/JSON），等待解析完成
2. **Agent**：管理台 → Agent → 新建 → 三步向导：
   - 基本信息（名称、头像、人格预设）
   - 挂载知识库（可多库）
   - 选择 LLM 配置（主模型 + 降级）
3. 创建后在 Agent 详情页可用「对话」Tab 直接测试问答

## 四、接入 QQ 机器人

> 前置：已完成[第 1-3 步](#三第一次使用三步完成配置)（LLM、知识库、Agent）。

### 4.1 QQ 开放平台准备

1. 打开 [QQ 开放平台机器人](https://q.qq.com)，创建机器人，获取 **AppID** 与 **AppSecret**
2. 机器人发布/上线（沙箱环境可先用测试）
3. 把机器人拉进目标 QQ 群

### 4.2 管理台配置

设置 → 机器人 → **QQ 官方机器人**：

1. 「配置」→ 填 AppID / AppSecret → 保存
2. 「测试凭据」→ 通过后点「**启用**」
3. 「获取群 OpenID」→ 点「开始获取」，**到目标群 @机器人 发任意消息**，5 分钟内回管理台「刷新结果」，得到群 OpenID
4. 「群 → Agent 绑定」→ 填群 OpenID，选择 Agent，绑定

### 4.3 使用

在绑定群内 **@机器人 提问**，机器人会引用你绑定的 Agent 及其知识库回答。

> QQ 群 OpenID 是平台分配的随机串（非群号），首次需通过「获取群 OpenID」流程采集。

### 4.4 私聊（单聊）

用户可**直接私聊机器人**提问（无需 @）。使用前：

1. **QQ 开放平台**：为机器人**开通单聊（私聊）场景**权限（平台侧申请，否则收不到私聊消息）
2. 管理台 → 机器人 → QQ 官方机器人 → 「回复与私聊设置」：
   - 打开**私聊开关**
   - 选择**私聊默认 Agent**（私聊由该 Agent 回答）
   - 选择**权限模式**：开放所有人 / 仅白名单可访问 / 黑名单不可访问
   - 白名单/黑名单模式点「名单设置」弹窗增删用户 OpenID（留空名单 = 白名单模式无人可访问 / 黑名单模式不屏蔽任何人）
3. 私聊的问答记录同样进入观测页（渠道 = QQ 机器人）

> 私聊用户 OpenID 形如 `xxx`（非群号）；可从观测页私聊记录的 user_id（`qq:c2c:...`）中看到。

## 五、接入飞书机器人

> 前置：已完成[第 1-3 步](#三第一次使用三步完成配置)。

### 5.1 飞书开放平台准备（约 5 分钟）

1. 打开 [飞书开放平台](https://open.feishu.cn) → 创建**企业自建应用**，记录 **App ID**（`cli_xxx`）与 **App Secret**
   - 若已配置过**飞书云文档导入**，可直接复用同一应用（无需重复填凭据）
2. 应用能力 → 添加**机器人**
3. 权限管理 → 开通：`im:message`、`im:message:send_as_bot`、`im:chat:read`（获取群信息）
4. 事件与回调 → 订阅方式选**使用长连接接收事件**，添加事件 `im.message.receive_v1`（无需公网回调地址）
5. 版本管理与发布 → **创建版本并发布上线**
6. 把机器人拉进目标飞书群（群设置 → 群机器人 → 添加机器人 → 选你的应用，**必须是应用机器人，不是自定义机器人**）

### 5.2 管理台配置

设置 → 机器人 → **飞书机器人**：

1. 凭据：可直接复用云文档应用（页面会提示"复用云文档飞书应用：cli_xxx"）；也可「配置」单独填 AppID/Secret
2. 「测试凭据」→ 通过后「启用」
3. 「机器人所在群」→「刷新群列表」→ 显示机器人已加入的群（**点群标签可直接绑定**）
4. 「群 → Agent 绑定」→ 选择 Agent

### 5.3 使用

在绑定飞书群内 **@机器人 提问**，机器人以引用回复回答。

### 5.4 私聊（单聊）

用户可**直接私聊机器人**提问（无需 @，机器人默认支持单聊，无需额外开通）。管理台 → 机器人 → 飞书机器人 → 「回复与私聊设置」：

1. 打开**私聊开关**
2. 选择**私聊默认 Agent**
3. 选择**权限模式**（开放所有人 / 仅白名单可访问 / 黑名单不可访问），白名单/黑名单通过弹窗管理用户 OpenID（`ou_xxx` 格式，可从观测页私聊记录 user_id 中看到）

### 5.5 飞书常见问题速查

| 现象 | 原因与解决 |
|---|---|
| 刷新群列表为空 | 群里加的是**自定义机器人**而非应用机器人 → 换成应用机器人；或应用可见范围未包含群成员 → 发布时选全部成员 |
| 获取群列表 502 | 未开 `im:chat:read` 权限，或应用未发布最新版本 → 补权限后重新发布 |
| 收不到消息 | 事件订阅未选**长连接**、未订阅 `im.message.receive_v1`、或改配置后未重新发布 |
| 测试凭据失败 | AppID/Secret 错误，或应用未发布上线 |

## 六、机器人通用设置（回复与私聊）

设置 → 机器人 → QQ/飞书 → 「**回复与私聊设置**」卡片：

### 回复详细程度

- **简洁（默认）**：1-3 段或少量要点，只保留必要背景
- **详细**：先给摘要结论，再展开背景、依据、完整步骤、风险与例外，对比用表格

> 独立于应用凭据配置，随时切换即时生效，QQ 与飞书各自独立设置。

### 私聊（单聊）设置

| 设置项 | 说明 |
|---|---|
| 私聊开关 | **默认关闭**；开启后用户可直接私聊机器人提问 |
| 私聊默认 Agent | 私聊消息由哪个 Agent 回答 |
| 权限模式 | **开放所有人** / **仅白名单可访问** / **黑名单不可访问** |
| 名单设置 | 白名单/黑名单模式下的用户 OpenID 列表（弹窗增删） |

安全边界：私聊开关默认关闭 → 权限模式决定谁可访问 → 未授权用户消息自动忽略（不触发模型）。

### 其他

- 机器人消息会做 **Markdown 降级清洗**（代码块、表格、列表、链接转为纯文本后发送），保证在群内正常展示
- 群聊只响应**已绑定群**内 **@机器人** 的消息，未绑定群的消息自动忽略
- 内置**限流与并发保护**，防刷消息导致模型调用滥用

## 七、问答观测

管理台侧边栏 → **问答观测**：全渠道问答链路可视化，自动统计**管理台 / QQ 机器人 / 飞书机器人**的每一次问答。

### 7.1 渠道卡片

- 每个渠道一张卡片（与 LLM 配置同款卡片样式）：**总问答数 · 今日问答 · 最近问答时间**
- 点击卡片进入该渠道的问答详情

### 7.2 渠道详情

- 表格：时间（相对时间显示）· Agent · 问题 · 回答 · Token（输入/输出）· 耗时 · 状态（缓存 / 网络搜索 / 降级）
- 支持按 **Agent 筛选**、**关键词搜索**、分页
- 点击「详情」查看完整问题/回答、**引用来源 JSON**、chat_id/user_id、指标

### 7.3 数据来源

所有渠道的回答（管理台、QQ 群/私聊、飞书群/私聊）都会自动写入问答记录，无需额外配置；若接入 Langfuse，回答同时以上报 `source=qq-bot / feishu-bot / user-web` 渠道标签。

## 八、常见问题 FAQ

> 按关键词检索：`启动` `部署` `python` `端口` `登录` `LLM` `向量化` `知识库` `飞书` `QQ` `群` `凭据` `收不到` `空列表` `502`

### 启动与部署

**Q：`python: command not found`**
macOS 无 `python` 命令，使用 `python3` 或虚拟环境内的 `./.venv/bin/python`。

**Q：提示"已有实例在运行，退出"**
进程单实例锁被占用：关闭已运行的智答引擎窗口/进程后重新启动。

**Q：端口被占用怎么办？**
应用会自动选择可用端口（日志显示实际端口）。想固定端口，改 `backend/.env` 或环境变量 `ZHIDA_API_PORT`。

**Q：如何确认服务正常？**
访问 `http://127.0.0.1:18900/health`，返回 `{"status":"ok"}` 即正常。

### 登录与账号

**Q：管理员初始密码是什么？**
首次启动引导页会初始化管理员账号；如忘记，删除数据目录后重启会重新引导（注意：会清空数据，谨慎操作）。

**Q：用户端怎么访问？**
管理员在「访问码」中生成一次性激活码，用户用它登录用户站（Agent 需勾选公开/授权）。

### 模型与知识库

**Q：问答没有用知识库内容？**
1. 确认 LLM 已测试通过；2. 确认向量化已配置（云端 Key 或本地模型）；3. 确认 Agent 已挂载知识库且文档索引完成（知识库列表看状态）。

**Q：上传文档后一直"解析中"？**
首次向量化需加载模型/调用 API，耐心等待；失败可查看日志（见[附录](#八附录数据与日志位置)）。

**Q：支持哪些文件格式？**
PDF、DOCX、Excel（xlsx/csv）、Markdown、TXT、JSON；复杂 PDF 可另配 MinerU 解析（可选）。

**Q：怎么导入飞书云文档？**
管理台 → 知识库 → 选择知识库 → 「飞书导入」：先配置飞书应用（设置 → 云文档配置），粘贴文档/知识空间链接即可导入。

### 机器人渠道

**Q：QQ 收不到机器人回复？**
1. 机器人已「启用」；2. 群已绑定 Agent；3. 群里 **@机器人**（不是直接发消息）；4. 看日志是否提示"该群尚未绑定 Agent"。

**Q：QQ 日志一直 `Gateway 断开：'access_token'`？**
AppID/AppSecret 未配置或错误（QQ 凭据未配置时 Gateway 会循环重试，属正常现象）。

**Q：飞书「刷新群列表」按钮是灰的？**
需先「启用」飞书机器人（未启用时群列表按钮禁用）。

**Q：飞书群里 @ 机器人没反应，日志也没有长连接记录？**
检查应用是否启用、凭据是否正确、事件订阅是否为长连接并发布最新版本。

**Q：飞书能不能复用云文档的应用？**
能。机器人未单独填凭据时自动复用云文档飞书应用（前提：该应用已开启机器人能力并发布）。

**Q：如何开启机器人私聊？**
机器人设置 → 「回复与私聊设置」→ 打开**私聊开关** → 选**私聊默认 Agent** → 选**权限模式**。QQ 需先在开放平台开通单聊场景；飞书默认支持。

**Q：私聊白名单/黑名单里的用户 OpenID 从哪里来？**
从「问答观测」进入渠道详情，查看私聊记录的 `user_id`（飞书 `feishu:...` 为 `ou_xxx`，QQ `qq:c2c:...` 为用户 OpenID），复制到名单管理弹窗即可。

**Q：观测页看不到机器人问答？**
1. 确认应用已重启（观测写入是较新功能）；2. 渠道卡片需有点击刷新；3. 机器人渠道正常应答后自动入库；4. 可先在管理台「问答观测」看是否有数据。

**Q：管理台怎么没有"对话"了？**
管理端对话功能已移除，问答统一走机器人渠道与用户端。

### 其他

**Q：如何查看运行日志？**
见[附录](#八附录数据与日志位置)日志目录，按天滚动，保留 30 天。

**Q：数据存在哪里、会丢失吗？**
全部数据在本地数据目录（SQLite + ChromaDB + 文件），不依赖云服务；备份该目录即可迁移。

## 九、附录：数据与日志位置

| 项 | macOS | Windows |
|---|---|---|
| 数据目录 | `~/Library/Application Support/ZhidaEngine/` | `%LOCALAPPDATA%\ZhidaEngine\` |
| 数据库 | 数据目录下 `zhida_engine.db` | 同左 |
| 向量库 | 数据目录下 `chroma_db/` | 同左 |
| 日志 | 数据目录下 `logs/zhida_YYYY-MM-DD.log`（保留 30 天） | 同左 |
| 配置文件 | `backend/.env`（可选） | 同左 |

**备份 = 拷贝整个数据目录**；恢复 = 停止应用，替换目录，重启。

# 飞书机器人渠道接入指南

> 智答引擎（ZhiDa Engine）—— 飞书群机器人渠道（Feishu Bot）
> 状态：✅ 已实现（后端服务 + 管理台页面）

## 功能

在飞书群内 **@机器人** 发送消息，由绑定的 Agent 基于知识库回答（引用回复原消息）。与 QQ 官方机器人渠道同构。

- 消息接收：飞书官方 **WebSocket 长连接**（lark-oapi SDK），无需公网回调地址
- 群绑定：管理台直接列出机器人已加入的群，选择绑定 Agent（无需手动获取群 ID）
- 凭据加密存储：App Secret 与 QQ 一致使用 AES 加密落库

## 一、飞书开放平台侧配置（约 5 分钟）

1. 打开 [飞书开放平台](https://open.feishu.cn/) → 创建**企业自建应用**，记录 **App ID**（`cli_xxx`）与 **App Secret**
2. 应用能力 → 添加 **机器人** 能力
3. 权限管理 → 开通以下权限（scope）：
   - `im:message`（读取消息）— 接收群消息事件
   - `im:message:send_as_bot`（以应用的身份发消息）— 回复
   - `im:chat:read`（获取群信息）— 群列表/群名
   - `im:resource`（获取消息中上传的文件）— 备用
4. 事件与回调 → 订阅方式选择 **使用长连接接收事件**，添加事件：`im.message.receive_v1`（接收消息）
5. 版本管理与发布 → 创建版本并**发布上线**（机器人须在企业内可用）
6. 把机器人拉入目标飞书群

> 长连接模式不需要配置公网回调地址，桌面应用开箱即用。

## 二、智答引擎侧配置

1. 管理台 → 设置 → **机器人** → **飞书机器人**
2. 点击「配置」，填入 App ID / App Secret，保存
3. 点击「测试凭据」确认可用，然后点击「启用」
4. 在「群 → Agent 绑定」卡片点击「刷新群列表」，选择目标群 + 回答该群消息的 Agent，点击「绑定」
5. 回到飞书群 @机器人 提问验证

## 四、注意事项

- **群消息必须 @ 机器人** 才会触发回答（p2p 单聊第一版不支持，仅群聊）
- 只处理文本消息；Markdown 会做降级清洗后以纯文本引用回复（与 QQ 渠道一致）
- 修改 App ID/Secret 或启停后自动重建长连接（服务内部 generation 守卫，旧事件丢弃）
- 权限未开通时常见报错：
  - 群列表加载失败 → 检查 `im:chat:read` 权限与机器人是否已入群
  - 收不到消息 → 检查长连接订阅 `im.message.receive_v1` 与应用是否已发布上线

## 五、后续可扩展

- p2p 单聊支持（去除 chat_type == "group" 限制即可）
- 富文本/卡片回复（飞书 interactive card）
- 从飞书文档/多维表格导入知识（已有 `/knowledge/feishu/*` 云文档导入，二者可共用同一应用凭据）
